2. manifest.json 設定

アプリ名を入力してください

説明文を入力してください

3. sw.js 設定

-pwa-v2
キャッシュ識別子を入力してください（半角英数字・ハイフン）
インストール画面（情報が追加されたUI）の表示に必要です。screenshot-wide.png（1280×720）と screenshot-mobile.png（390×844）をアプリと同じフォルダに置いてください。アイコン作成アプリで作成できます。

4. 「プログラムから開く」設定（任意）

有効にすると、インストールしたアプリが OS の「プログラムから開く」に表示され、選んだ種類のファイルから直接起動できるようになります。対応は Chromebook / Windows の Chrome のみです（Android / iPhone は未対応）。
拡張子を入力してください 起動時に渡されたファイルは、アプリ内の最初のファイル選択（input type="file"）に自動で渡されます。アプリ側で window.onPwaFileOpen = function (file) { ... } を定義すると、そちらが優先されます。
